# 人工验收

323本机结果见[验证记录](validation.md)。以下步骤用于后续设备、输入法版本或功能改动的复验。

## 准备

安装并启用目标输入法，填写其实际语音快捷键，手动完成RimeDou辅助功能与输入监控授权。在可编辑的空白输入框切到RIME或日常输入法。

## 正常开始与停止

1. 菜单选择豆包，右Command开始语音，说测试短句后再次点按停止。
2. 确认文字提交、日常输入法恢复，再输入少量字母或数字检查后续响应和顺序。
3. 用鼠标侧键重复以上步骤。
4. 选择千问，分别用右Command和鼠标侧键重复测试。

## 千问Esc取消

1. 用侧键开始千问语音，说话中按单独Esc取消。
2. 确认窗口关闭、日常输入法恢复，再按侧键检查能否开启下一次语音。
3. 用右Command重复，检查菜单状态及后续键盘响应。
4. 取消后立即输入少量字符，检查恢复后的顺序及Esc是否进入原输入框。
5. 按需要检查长按Esc、刚开始就取消、已请求停止后取消和恢复中再次取消。

用户于2026-11-13确认两种入口都能在Esc取消后再次唤起，实际日志与反馈一致。

## 异常恢复与单来源

- 等待识别期间输入少量字符，检查补发顺序；切换窗口后再回原窗口，检查暂存去向。
- 暂存受阻时，确认语音结束并关闭厂商窗口，再选择继续补发或“确认语音已结束，丢弃暂存并恢复快捷键”。检查恢复结果及失败提示。
- 直接用厂商原生语音键结束，检查RimeDou恢复后保持空闲。
- 仅启用一家来源时，完成对应步骤，并检查另一家不可选；更改系统输入法列表后核对菜单与配置提示。
- 唤起失败时，同时记录厂商原生语音键是否可用，以及RimeDou日志是否进入启动流程。
